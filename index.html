Centro

El promedio de todas las medias muestrales coincide con la media poblacional.

E(x̄) = μ

Dispersión

Al aumentar el tamaño de la muestra, disminuye la variabilidad entre medias muestrales.

Var(x̄) = σ² / n

Error estándar

Mide cuánto tienden a variar las medias muestrales alrededor de μ.

EE = σ / √n
No confundir: la desviación estándar describe la dispersión de valores individuales; el error estándar describe la dispersión de un estadístico entre muestras.

Teorema Central del Límite

A medida que aumenta n, la distribución de las medias muestrales tiende a una Normal bajo las condiciones estudiadas. No afirma que los datos individuales se vuelvan normales.

z = (x̄ − μ) / (σ / √n)

Visualizá el TCL

Muchas medias muestrales tienden a concentrarse alrededor de μ. Cuando n crece, el error estándar disminuye.

Estimación de parámetros

Usamos lo que observamos en la muestra para aproximarnos a un parámetro poblacional desconocido.

Estimación puntual

Un estadístico ofrece un único valor como estimación.

x̄ → μ    p̂ → P

Limitación: un único número no expresa la incertidumbre.

Estimación por intervalo

Construimos un rango acompañado por un nivel de confianza.

estimador ± error de estimación

La precisión depende de confianza, variabilidad y tamaño muestral.

Simulador de IC para una media

Intervalo aproximado
6.26 — 6.74

EE = 0.120

Interpretación del 95%: si repitiéramos muchas veces el procedimiento, aproximadamente el 95% de los intervalos construidos de esta forma contendría al parámetro verdadero. El nivel de confianza se refiere al procedimiento, no al porcentaje de personas dentro del intervalo.

Más confianza

z mayor → intervalo más ancho → menor precisión.

Más variabilidad

s mayor → error estándar mayor → intervalo más ancho.

Más casos

n mayor → error estándar menor → intervalo más estrecho.

Atención con n: aumentar el tamaño muestral reduce el error muestral, pero no corrige una muestra mal seleccionada o no probabilística. Para muestras pequeñas, en tus clases se advierte considerar t de Student bajo los supuestos correspondientes.

H₀

Expresa el valor o afirmación que se somete a contraste. La prueba evalúa qué tan compatible es el resultado muestral con H₀.

p-valor

Resume cuán extremo resulta el dato observado bajo H₀. Si p < α, se rechaza H₀.

p < α → rechazar H₀

Errores posibles

Tipo I: rechazar H₀ siendo verdadera. Tipo II: no rechazar H₀ siendo falsa.

Ejemplo integrador

H₀ propone μ₀ = 50; σ = 10; n = 100, por lo que EE = 1. Si obtenemos x̄ = 52, entonces zobs = 2. En una prueba bilateral con α = .05, zc = ±1,96: como 2 > 1,96, se rechaza H₀.

zobs = (52 − 50) / 1 = 2

Probá una decisión con p-valor

α se fija antes de observar la muestra. En una prueba bilateral con α=.05, el 5% se reparte entre ambas colas.

DecisiónRechazar H₀p = .030 < α = .05

01

Tipos de relación entre variables

Simétrica / Asimétrica

Una relación es asimétrica cuando una variable antecede (lógica o cronológicamente) a la otra: hay una antecedente y una consecuente. Cuando no puede establecerse esa precedencia, la relación es simétrica.

Directa / Inversa

En variables de nivel ordinal o superior: es directa si al aumentar una, aumenta la otra. Es inversa si al aumentar una, la otra disminuye.

¿Y la intensidad?

Sea la relación simétrica o asimétrica, y pueda o no definirse su dirección, siempre es posible medir la intensidad: la fuerza con que los cambios de una variable afectan (o acompañan) a los de la otra. Eso es justamente lo que hacen los coeficientes que vas a explorar en las próximas pestañas.

Idea intuitiva

"X tiene mucha influencia en Y" — esa noción de mucha o poca influencia es la intensidad de la relación.

03

El concepto de independencia estadística

¿Qué significa "independencia"?

Dos variables son independientes cuando una no influye en la otra: el rendimiento no dependería del tipo de docente. Para comprobarlo, se compara la tabla real contra la tabla que debería darse si las variables fueran independientes (frecuencias esperadas).

fij = (fi · fj) / n   →   (total fila × total columna) / total general

04

Q de Kendall (tablas 2×2)

Coeficiente para evaluar la intensidad de una relación entre dos variables dicotómicas. Usa el modo en que las frecuencias se concentran en las diagonales de una tabla 2×2.

Q = (A·D − C·B) / (A·D + C·B)

Va de −1 a 1. Cuanto más cerca de ±1, más intensa la relación; cerca de 0, relación débil o inexistente.

05

Chi-cuadrado, C de Pearson y V de Cramer

Chi-cuadrado (χ²)

Prueba no paramétrica que determina si existe relación significativa entre dos variables categóricas, comparando frecuencias observadas vs. esperadas.

χ² = Σ [ (fobs − fesp)² / fesp ]

Si p < 0,05 se rechaza la hipótesis de independencia. Limitación: no dice qué tan fuerte es la asociación, solo si existe — y crece con el tamaño muestral, por eso se "normaliza" con C de Pearson o V de Cramer.

C de Pearson

C = √( χ² / (χ²+n) )

Entre 0 y 1, pero su máximo teórico depende del tamaño de la tabla — rara vez llega a 1.

V de Cramer

V = √( χ² / (n·mín(f−1,c−1)) )

Entre 0 (sin asociación) y 1 (asociación perfecta). Es el estándar para comparar tablas de cualquier tamaño.

06

Correlación por rangos de Spearman

Se usa cuando ambas variables son ordinales (o una ordinal y otra intervalar/proporcional). Mide la relación monotónica: si al subir el orden de una, sube o baja consistentemente el orden de la otra — no necesariamente en línea recta.

Para calcularlo, se transforman los valores de cada variable en rangos (1 = el mayor valor, 2 = el siguiente, y así sucesivamente) y se correlacionan esos rangos, no los valores originales.

Ejemplo del apunte

Orden de mérito en el ingreso a una carrera vs. nivel de educación de la madre: ambas son ordinales, así que no conviene armar una tabla de doble entrada (queda demasiado dispersa) — directamente se calcula el coeficiente de Spearman sobre los rangos.

Relación directaAl aumentar una variable ordinal o superior, aumenta la otra.
Relación inversaAl aumentar una variable, la otra disminuye.
IntensidadFuerza con que los cambios de una variable afectan o acompañan a los de la otra.
Independencia estadísticaDos variables son independientes cuando una no influye en la otra.
Frecuencia esperadaLa que "debería" darse en cada celda si las variables fueran independientes: (total fila × total columna) / n.

Idea central

Toda relación entre variables puede describirse en tres planos: su tipo (simétrica/asimétrica, directa/inversa), su existencia (independencia vs. asociación) y su intensidad (el coeficiente adecuado según el nivel de medición).

Para llevarte

  • Antes de elegir un coeficiente, identificá el nivel de medición de cada variable.
  • Con dos variables de distinto nivel, siempre manda el nivel más bajo.
  • Chi-cuadrado dice si hay relación; V de Cramer o C de Pearson dicen qué tan fuerte es.
  • Spearman es para relaciones monótonas y ordinales; Pearson exige linealidad y variables cuantitativas.
